# LichSOMA's Speaker Selector

> **이 모듈은 생성형 AI의 도움으로 제작되었습니다.**

## 호환성

- **Foundry VTT**: v13 이상, v14 확인 (`module.json` 기준)

## 소개

Foundry VTT의 채팅 시스템을 확장하는 모듈입니다. 토큰 선택과 독립적인 스피커 선택, 채팅 커스터마이징, 나레이터 모드, 채팅 로그 HTML 내보내기·아카이브 등을 제공합니다.

## 주요 기능

### 스피커 선택

- 토큰 선택과 독립적으로 말하는 캐릭터를 선택할 수 있습니다.
- 채팅 입력 영역 근처의 드롭다운에서 스피커 선택.
- OOC(Out of Character) 모드 지원(설정 조합에 따라 옵션 표시).

### 스피커 설정 (GM)

- 채팅 입력 창의 설정 버튼으로 사용 가능한 액터 관리.
- 드래그 앤 드롭으로 액터 추가·제거, 검색.

### 감정 시스템

- 액터별 감정 표정 설정 및 채팅 포트레잇 반영.

### 채팅 커스터마이징

- **포트레잇**: 크기·표시 옵션.
- **웹폰트 CSS**: 헤더·메시지·주사위·나레이터 폰트를 `@font-face` CSS로 설정합니다. 각 CSS의 첫 `font-family`와 단일 `font-weight`, `font-style`, `font-variation-settings` 값이 게임 내부와 HTML 로그 출력에 공통 적용됩니다.
- **D&D 5e 웹폰트**: D&D 5e 헤더의 이름과 보조 정보에 각각 별도의 웹폰트 CSS를 지정할 수 있습니다.
- 웹폰트 CSS가 비어 있으면 폰트 패밀리를 지정하지 않고 Foundry의 기본 폰트를 그대로 사용합니다. 기본값은 헤더 900/정체, 메시지 500/정체, 나레이터 바 900/이탤릭, 나레이터 카드 500/이탤릭입니다. 웹폰트 CSS에 해당 속성을 적으면 그 값이 우선합니다.
- **유저 색상**: 발신자 이름에 유저 색 적용.
- **채팅 머지**: 같은 스피커 연속 메시지에서 헤더 생략(설정으로 켜기).
- **메시지 수정·삭제**: 메시지를 수정하거나 삭제할 수 있으며, 수정 완료·취소 후 채팅 입력창으로 포커스가 돌아옵니다. 삭제 버튼에 호버하면 대상 메시지가 붉게 강조됩니다.
- **마크다운·루비**: `~~취소선~~`, `*이탤릭*`, `**볼드**`, `[[본문|루비]]` 등.

### 사이드바·채팅 입력 크기 조절

- 사이드바 **왼쪽 가장자리**를 드래그해 너비 조절(저장된 최소 너비 이상).
- 채팅 입력 영역 **상단 가장자리**를 드래그해 입력 칸 높이 조절(`--chat-input-height`).

### 채팅 입력 — 이미지 삽입

- 채팅 컨트롤(저장·비우기 버튼 근처)에 **이미지 삽입** 버튼을 제공하고, 기본 ProseMirror 상단 포맷 메뉴는 숨겨 두어 UI를 단순화합니다.

### 나레이터 모드 (GM)

- 나레이터 버튼·`Shift+Space` 토글 단축키·타이핑 효과·사운드·스타일 설정·나레이터 바 페이드인/페이드아웃.
- `/desc …` 로 나레이터 카드 형태 출력 등.

### 채팅 로그 HTML 내보내기

- 채팅 패널의 저장 아이콘 동작을 가로채 **단일 HTML 파일**로 저장.
- 모듈 기본 스타일(`lichsoma-chat-log-export.css`) 인라인 포함.
- **설정**: 상대 경로 기준 URL(`chatLogExportBasePath`), 이미지 **Base64 포함 여부**, 내보낸 HTML에서 **주사위 툴팁 표시 여부**, **커스텀 CSS**(월드 저장 + 설정 화면에서 코드 편집 메뉴). 게임 내부 폰트와 HTML 출력 폰트는 별도 설정이 아니라 동일한 웹폰트 CSS 설정을 공유합니다.
- Base64 옵션을 사용하면 500KB 이하 이미지만 내장하며, 동일한 최종 Data URL은 HTML 안에 한 번만 저장합니다. 500KB를 초과한 이미지는 절대 URL을 유지합니다.
- **참고**: 메시지 수가 매우 많으면 브라우저에서 처리 시간·메모리 부담이 커질 수 있습니다.

### 시스템별 채팅 스타일 / HTML 내보내기 스타일

- 시스템별 인게임 채팅 보정은 `styles/systems/lichsoma-chat-<system>.css`에 분리되어 있습니다. 현재 `dnd5e`, `lancer`, `dx3rd` 보정 파일을 포함합니다. `cain-alter`는 시스템 자체의 HTML 출력 어댑터를 사용합니다.
- HTML 내보내기 전용 시스템 보정은 `styles/export/lichsoma-chat-<system>-export.css`에 분리되어 있으며, 각 시스템 전용 스크립트가 현재 월드의 시스템에 맞는 CSS만 추가로 주입합니다.
- LANCER 내보내기는 LANCER 시스템 CSS와 아이콘 보정이 필요하므로, 정적 우선순위 보정은 `styles/export/lichsoma-chat-lancer-export.css`에서 관리하고, 시스템 원본 CSS/아이콘 fallback은 `scripts/apps/lichsoma-chat-lancer.js`가 계속 수집합니다.

### 채팅 로그 아카이브

- 과거 로그 폴더 탐색·검색.

### LANCER 파일럿 이름/콜사인 표시

- 게임 시스템이 **LANCER**일 때, 파일럿 채팅의 발신자 표시는 콜사인이 아니라 파일럿의 실제 이름을 우선 사용합니다.
- 파일럿 콜사인이 있으면 실제 이름 위에 루비 문자로 표시합니다.
- LANCER 시트에서 판정·무기·스킬 등을 실행해 생성된 채팅 카드에도 같은 표시 규칙을 적용합니다.
- 메크 액터가 파일럿과 연결되어 있으면 메크 이름 위에 파일럿 콜사인을 루비 문자로 표시합니다. 파일럿이 연결되어 있지 않은 메크는 루비 없이 메크 이름만 표시합니다.
- 메크 액터가 파일럿과 연결되어 있는 경우에도 가능한 범위에서 연결된 파일럿의 이름/콜사인을 사용합니다.

### 타이핑 표시

- 다른 사용자 입력 중 표시.

### FVTT v13 채팅 사이드바 보정

- FVTT v13에서는 채팅 입력창을 textarea로 가정하지 않고 ProseMirror 계열 입력창을 기준으로 높이 조절 핸들을 적용합니다.
- FVTT v13에는 채팅 에디터의 이미지 삽입 기능이 없으므로, 모듈이 별도의 이미지 삽입 버튼을 생성하지 않습니다.
- FVTT v13의 채팅 입력창 최소 높이는 128px로 유지됩니다.

- FVTT v13에서 채팅 입력창 높이 조절이 실제 ProseMirror 입력 루트까지 반영되도록 보강했습니다. 높이 조절 핸들은 v13 DOM 구조에 맞춰 채팅 form 기준으로 고정됩니다.

**2.1.0 LANCER 파일럿 이름 표시 보강**
LANCER 파일럿의 콜사인을 채팅 발신자 이름으로 쓰지 않고, 실제 이름을 표시하며 콜사인은 루비 문자로 표시하도록 개선했습니다. LANCER 시트 판정 채팅에도 같은 표시 규칙을 적용합니다.

**2.1.0 LANCER 시트 롤 포트레잇/머지 보강**
LANCER 시트에서 판정으로 생성된 메시지도 speaker 데이터를 ID 기반으로 정규화해 포트레잇·머지 플래그가 새로고침 후에도 유지되도록 개선했습니다.
기존에 플래그가 없는 과거 LANCER 시트 롤 메시지도 렌더링 시 액터/감정 정보를 fallback으로 사용해 포트레잇과 머지 조건을 최대한 복원합니다.

**2.1.0 LANCER 메크 콜사인 루비 표시 보강**
메크 액터가 파일럿과 연결되어 있을 경우 메크 이름을 유지하면서 파일럿 콜사인을 루비 문자로 표시하도록 개선했습니다. 파일럿이 없는 메크는 루비 없이 기존 이름만 표시합니다.

**2.1.0 말줄임표 자동 변환 보강**
채팅 입력에서 `...`를 입력하면 메시지 생성 시 실제 표시 텍스트를 `…`로 변환하도록 개선했습니다. HTML 태그나 속성은 건드리지 않고 텍스트 노드만 변환합니다.

**2.1.0 LANCER HTML 내보내기 CSS 보강**
LANCER 시스템에서 스피커 셀렉터의 HTML 로그 출력 시 LANCER 채팅 카드 관련 CSS와 아이콘/폰트 CSS를 함께 포함하도록 개선했습니다. 단, 채팅 메시지 프레임과 메시지 본문의 padding/background는 LANCER 원본 CSS가 아니라 스피커 셀렉터 스타일을 우선하도록 처리합니다. FVTT 13에서 보정한 채팅 줄간격과 메시지 간격도 HTML 출력에 반영되도록 내보낸 문서에 FVTT 버전용 class와 `chat-scroll` class를 추가했습니다.


**2.1.8-performance.6**
HTML 로그의 500KB 이하 이미지를 단일 이미지 레지스트리로 통합했습니다. 동일 URL의 중복 fetch와 서로 다른 URL에서 생성된 동일 Base64의 중복 저장을 방지합니다. 500KB를 초과한 신규 이미지는 Base64로 변환하지 않고 절대 URL을 유지합니다.

**2.1.8-performance.7**
채팅 메시지 수정 중 본문 하이라이트 색상을 `#ffd700`으로 변경하고, 일반 및 D&D 5e 네이티브 헤더의 메시지 삭제 버튼 호버 색상을 `#ff3b30`으로 통일했습니다. 삭제 버튼에 호버하는 동안 해당 메시지의 헤더와 본문 텍스트도 `#ff3b30`으로 표시됩니다.

**2.1.8-performance.9**
메시지 수정을 저장하거나 Escape로 취소한 직후 기본 채팅 입력창으로 포커스가 돌아오도록 개선했습니다. 다른 메시지로 수정 대상을 전환할 때는 채팅 입력창으로 포커스를 이동하지 않습니다.



### 2.1.8-performance.10
- 기존 `cain` 시스템 전용 어댑터와 인게임/HTML 출력 CSS를 제거했습니다. `cain-alter` 연동은 시스템 자체 어댑터와 우선순위 브리지를 그대로 사용합니다.
- 시스템 CSS 로더, 웹폰트 이름 추출, 메시지 작성자 해석, Base64 인코딩을 공통 유틸리티로 통합했습니다.
- D&D 5e의 `name-stacked`/`title`/`subtitle` 구성과 발화자명 적용을 인게임과 HTML 출력이 같은 코드로 사용하도록 통합했습니다.
- 스피커 격자와 메시지 발신자 수정 창의 액터 접근 권한·태그 검색·폴더 트리 구성 및 렌더링을 단일 구현으로 통합했습니다.

### 2.1.8-performance.11
- 렌더 제한으로 제거한 과거 메시지의 DOM 요소는 보관하지 않고 ID만 캐시합니다. 메시지 문서는 그대로 유지하며, 위로 스크롤하면 모듈이 제거했던 연속 구간을 먼저 다시 렌더링하고 그보다 오래된 기록은 Foundry VTT의 기본 기록 로더가 처리합니다.
- HTML 출력 버튼 감시 범위를 `document.body` 전체에서 현재 채팅 컨테이너 하나로 축소하고, 컨테이너가 교체되면 이전 옵저버를 해제합니다.
- D&D 5e 헤더의 발화자명·부제·아바타 재적용을 메시지당 하나의 제한된 재시도 작업으로 통합했습니다.
- 최근 12개를 제외한 오래된 채팅 메시지에 `content-visibility: auto`를 적용해 화면 밖 레이아웃·페인트 비용을 줄였습니다.

### 2.1.8-performance.12
- D&D 5e 네이티브 아바타를 제외한 스피커 헤더 포트레잇 영역을 항상 정사각형으로 고정했습니다.
- 세로형 이미지는 원본 비율을 유지한 채 포트레잇 높이에 맞추고 좌우 여백을 허용합니다.
- 가로형 이미지는 높이에 맞춘 뒤 좌우 초과분만 중앙 기준으로 잘라내며, 가로 방향으로 압축하거나 늘리지 않습니다.
- 동일한 표시 규칙을 HTML 채팅 로그 출력과 Base64 이미지 레지스트리 출력에도 반영했습니다.
### 2.1.8-performance.13

- 나레이터 타이핑 문자열을 최초 한 번만 파싱하고, 글자별 DOM 전체 재생성을 제거했습니다.
- `[[본문|루비]]`는 하나의 `<ruby>`를 유지하며 본문 진행률에 맞춰 루비 전체 문자열이 연속적으로 점진 노출됩니다.
- 글자마다 전송하던 나레이터 사운드 소켓을 제거하고 각 클라이언트에서 로컬 재생하도록 최적화했습니다.
- D&D 5e, DX3rd, LANCER 어댑터와 인게임 CSS는 현재 활성 시스템에 해당하는 파일만 조건부로 로드합니다.



### 2.1.8-performance.14

- 채팅 메시지 렌더 처리를 하나의 `renderChatMessageHTML` 파이프라인으로 통합하고, 스피커 표시 → 인라인 서식 → 수정 상태 → 머지 → 렌더 제한 순서를 명시했습니다.
- 모듈 소켓 수신을 단일 라우터로 통합하고, 메시지 유형·사용자 ID를 검증한 뒤 각 기능 핸들러로 전달합니다.
- `window.SpeakerSelector`, `window.LichsomaChatRenderLimiter`, `globalThis.LichsomaChatSystemRegistry` 전역 노출을 제거하고 `game.modules.get("lichsoma-speaker-selector").api`로 통합했습니다.
- 헤더 폰트 웨이트와 나레이터 폰트 굵기 설정을 제거했습니다. 폰트 굵기는 각 웹폰트 CSS에서 직접 지정합니다.
- 헤더·메시지 한자 전용 웹폰트 CSS 설정과 한자별 DOM 래핑을 제거했습니다.


### 2.1.8-performance.15

- 웹폰트 CSS의 `font-weight`, `font-style`, `font-variation-settings`를 헤더·메시지·주사위·나레이터와 HTML 출력에 자동 적용합니다.
- 웹폰트 CSS가 비어 있을 때는 폰트 패밀리를 지정하지 않고 Foundry의 기본 폰트를 상속합니다.
- 기본 타이포그래피를 헤더 900/정체, 메시지 500/정체, 나레이터 바 900/이탤릭, 나레이터 카드 500/이탤릭으로 정리했습니다.
- 별도 나레이터 이탤릭 설정을 제거하고 웹폰트 CSS가 입력된 경우 해당 스타일 값을 우선합니다.


### 2.1.8-performance.16

- GM은 `Shift+Space`로 나레이터 모드를 켜고 끌 수 있습니다.
- 일반 설정 입력창·검색창·CodeMirror에서는 단축키가 작동하지 않으며, Foundry 채팅 입력창에서는 현재 포커스를 유지한 채 사용할 수 있습니다.
- 메인 채팅과 팝아웃에 표시된 나레이터 버튼의 `aria-pressed` 상태를 함께 동기화합니다.

### 2.1.8-performance.17

- 나레이터 바 생성 시 초기 `opacity: 0` 상태를 실제 프레임에 반영한 뒤 다음 프레임에서 `opacity: 1`로 전환하여 페이드인이 확실히 실행되도록 수정했습니다.
- 페이드아웃 중 다시 나레이터 모드를 켰을 때 이전 제거 타이머가 새 라인을 지우지 않도록 진입·제거 전환 타이머를 통합 관리합니다.
